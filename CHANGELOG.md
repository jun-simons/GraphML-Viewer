# Change Log

All notable changes to the "graphml-viewer" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.2]

### Fixed

- **GraphML: Open Preview** is now always available in the Command Palette, even with no editor or an unrelated file open ([#1](https://github.com/jun-simons/GraphML-Viewer/issues/1))
- Running the command from an unrelated file now prompts for a file instead of trying to render the active file
- Active `.graphml` / `.xml` files are matched case-insensitively (e.g. `.GRAPHML`)
